# Repository Overview

This is an empty GitHub Pages personal site repository (`username.github.io` pattern). No code, build system, or configuration exists yet.

## Getting Started

GitHub Pages supports several site generators. Before building, determine the approach:

- **Jekyll** (default): Push Markdown/HTML to `main`; GitHub builds automatically. Requires `_config.yml` and optionally `Gemfile`.
- **Static HTML**: Add an `index.html` directly. No build step needed.
- **Other generators** (Hugo, Next.js, etc.): Set up a build pipeline and configure Pages to deploy from the build output directory or a dedicated `gh-pages` branch.
